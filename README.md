# 英语六级学习助手

一个零依赖、纯前端的 CET 词汇学习应用。用浏览器直接打开 `index.html` 即可使用，学习数据自动保存在本地（LocalStorage），关闭浏览器不会丢失。

**内置词库：6662 词**（四级基础词 4544 + 六级进阶词 2118），覆盖六级大纲全部词汇，98% 的词条带真题例句及中文翻译，515 词附六级真题选择题（含答案解析）。

## 功能模块

| 模块 | 说明 |
|------|------|
| 📇 单词卡片 | 3D 翻转卡片，显示单词 / 音标 / 释义 / 真题例句（含中文翻译）；支持四级基础 / 六级进阶筛选、智能排序（优先复习薄弱词）、洗牌；「认识了 / 再看看」一键标记 |
| ✏️ 选择题测验 | 每轮 10 题，四种题型：**六级真题选择**（原题 + 选项辨析解析）、英译中、中译英、例句填空；错题优先抽考；即时反馈 + 结束后错题回顾；键盘 1-4 快速作答 |
| 🔤 拼写练习 | 显示中文释义 + 音标并自动朗读单词，输入拼写后给出逐字母对错反馈；支持重复听音、首尾字母提示；Enter 键快速提交 |
| 📊 学习进度 | 总词数 / 已掌握 / 学习中 / 错题本 / 正确率统计；近 7 天答题柱状图；词汇掌握率环形图；错题本专项复习；一键清空数据 |

## 掌握规则

- 连续答对 **2 次** → 标记为「已掌握」
- 答错 → 回到「学习中」，并自动进入**错题本**
- 错题本中的词以 **4 倍权重** 出现在测验和拼写练习中
- 错题本中的词被标记「已掌握」后自动移出

## 探索系统 · DEEP-SEA EXPEDITION

学习进度被映射为一场深海下潜：**已掌握词数 = 下潜深度**（0m 海面 → 10909m 马里亚纳海沟）。

- **五个深度带**：阳光带 → 暮光带 → 午夜带 → 深渊带 → 超深渊带，每带有对应潜航员段位（表层观察员 → 海沟征服者）
- **下潜状态仪表盘**：进度页的深度计实时显示当前深度、所处区带、段位与进入下一区带还差多少词；页脚 DEPTH 读数联动
- **每日深海信标**：首页每天出现一个按日期确定性抽取的单词，点击「追踪此信号」直接跳到该卡
- **新发现标记**：首次见到的词在卡片上亮起「◉ 新发现 · NEW」
- **声呐发音**：卡片发音按钮点击时发出声呐波纹

## 快捷键

| 按键 | 作用 |
|------|------|
| 空格 | 卡片翻面 |
| ← / → | 上一个 / 下一个单词 |
| 1 - 4 | 测验中选择对应选项 |
| Enter | 拼写练习中提交 / 进入下一题 |

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无任何框架和构建工具
- 发音使用浏览器原生 **Web Speech API**（Chrome / Edge 支持最佳）
- 数据持久化使用 **LocalStorage**（键名 `cet6_progress_v1`），清空浏览器数据会丢失进度
- `js/data.js`（约 1.6 MB）由 `tools/build-dict.js` 从原始词书数据生成，请勿手工编辑生成结果

## 词库来源与重建

原始数据来自开源项目 [kajweb/dict](https://github.com/kajweb/dict)（有道考神团队四级/六级真题核心词，含音标、释义、真题例句和真题选择题）。

重新构建词库：

```bash
# 1. 下载原始数据（book/ 目录下的 CET4_*.zip 与 CET6_*.zip），解压到同一目录
# 2. 运行构建脚本
node tools/build-dict.js <解压后的数据目录>
```

构建规则：四级书先扫描标记为 `level 1`，六级书仅补充四级没有的词（`level 2`）；重复词条自动补例句、补真题；跳过含空格的短语。

## 手工追加单词

在 `js/data.js` 的 `WORD_DB` 数组中按以下格式追加即可，`id` 保持唯一：

```js
{ id: 6663, word: 'sustain', phonetic: "/sə'steɪn/", pos: 'v.', meaning: '维持；承受',
  level: 2, example: 'The soil cannot sustain this many crops.' }
```

`level: 1` 为四级基础词，`level: 2` 为六级进阶词；`example` / `exampleCn` / `exam` 为可选字段。
